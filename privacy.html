Política de Privacidade — CipherOS Studio

Última atualização: novembro de 2026.

CipherOS Studio é uma ferramenta de uso interno, operada pelo próprio criador de conteúdo, para publicar automaticamente vídeos próprios nas contas do TikTok do mesmo operador.

1. Dados tratados

A ferramenta acessa, via API oficial do TikTok, apenas os dados estritamente necessários para publicar vídeos na conta autorizada pelo próprio operador (token de autorização concedido via OAuth e informações de publicação, como título e configurações de privacidade do vídeo).

2. Nenhum dado de terceiros

A ferramenta não coleta, processa ou compartilha dados pessoais de outros usuários do TikTok. Não há coleta de dados de espectadores, seguidores ou qualquer conta além da do próprio operador.

3. Compartilhamento

Nenhum dado é vendido, compartilhado ou repassado a terceiros. Os dados de autorização ficam armazenados apenas na infraestrutura privada do operador.

4. Revogação de acesso

O operador pode revogar a autorização desta ferramenta a qualquer momento diretamente nas configurações da própria conta do TikTok.

5. Contato

Dúvidas sobre esta política podem ser enviadas para o e-mail de contato do operador.
